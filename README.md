# PriceForge Clicker

Портретный кликер на Unity 6 (WebGL) — игровой клиент для бэкенда [PriceForge](https://github.com/Platonovv/AspPriceForge): валюта за клики и автодоход, магазин улучшений.

**Стек:** Unity 6 · C# · VContainer · UniTask · uGUI · Newtonsoft.Json

## Как устроено

- **Composition root** — `GameStartup` (VContainer `LifetimeScope`): настройки, сервисы, UI и точки входа регистрируются в одном месте, зависимости приходят через конструкторы.
- **Состояние и логика отдельно от UI.** `Wallet` и `ClickerState` хранят данные, `ClickerService` начисляет за клик, `AutoIncomeTicker` (`ITickable`) — автодоход раз в секунду. Состояние реактивное: вьюхи подписываются на изменения и перерисовываются сами, медиаторы связывают их с сервисами.
- **Магазин за интерфейсом `IShopService`.** Асинхронный контракт на UniTask: получить предложения, купить. Сейчас работает `LocalShopService`; серверная реализация на HTTP подменяет её одной строкой регистрации — UI и логика не меняются.
- **Баланс в ScriptableObject.** Цены и эффекты улучшений (сила клика, автодоход, множитель), настройки кликера и UI — в `GameSettings` и вложенных SO, доступ через `AssetProvider`.

## Дальше

Серверный кошелёк в PriceForge (начисление с потолком, покупка в транзакции) и `HttpShopService` в клиенте: цена и списание проверяются на сервере, а не на устройстве игрока.

## Запуск

Открыть папку в Unity 6000.3, сцена `Assets/_Game/Scenes/Game.unity`, Play. Целевая платформа — WebGL.
