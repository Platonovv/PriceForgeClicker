# PriceForge Clicker

Портретный кликер на Unity 6 (WebGL) — игровой клиент для бэкенда [PriceForge](https://github.com/Platonovv/AspPriceForge): вход по аккаунту, монеты за клики и автодоход, магазин улучшений. Баланс, список предметов и покупки живут на сервере: клиент показывает только то, что подтвердил сервер.

**Стек:** Unity 6 · C# · VContainer · UniTask · uGUI · UnityWebRequest · Newtonsoft.Json

## Как устроено

- **Composition root** — `GameStartup` (VContainer `LifetimeScope`): настройки, сервисы, UI и точки входа регистрируются в одном месте, зависимости приходят через конструкторы. `GameFlow` показывает вход, а после него — игру, магазин и отправку монет.
- **Состояние и логика отдельно от UI.** `Wallet` и `ClickerState` хранят данные, `ClickerService` начисляет за клик, `AutoIncomeTicker` (`ITickable`) — автодоход раз в секунду. Состояние реактивное: вьюхи подписываются на изменения и перерисовываются сами, медиаторы связывают их с сервисами.
- **Сетевой слой.** `ApiClient` — транспорт на `UnityWebRequest` + UniTask: JSON, JWT в заголовке `Authorization`, `Idempotency-Key` для небезопасных запросов. Поверх него доменные клиенты: `AuthApi` (регистрация и вход, токен хранит `AuthSession`), `WalletApi` (баланс, начисление), `GameApi` (предметы и покупки).
- **Вход.** `LoginMediator`: регистрация и вход по почте и паролю, сообщения на 401 и 409; после входа баланс загружается с сервера.
- **Монеты на сервер пачками.** `EarnSender` раз в 3 с забирает из кошелька накопленные монеты (не больше 60 — в пределах серверного лимита) и отправляет `POST api/v1/wallet/earn` с `Idempotency-Key`. При сбое сети или ошибке сервера та же пачка уходит повторно с тем же ключом: монеты не теряются и не начисляются дважды. Баланс на экране — ответ сервера.
- **Магазин за интерфейсом `IShopService`.** Асинхронный контракт на UniTask: получить предложения, купить. `ServerShopService` загружает предметы и цены с сервера (`GET api/v1/game/items`) и покупает через `POST api/v1/game/purchases`; ключ идемпотентности создаётся на попытку покупки предмета и сохраняется для повтора при сбое сети. Кнопка покупки смотрит на подтверждённый сервером баланс, отказ (не хватает монет, ошибка) показывается сообщением. Локальная реализация заменена серверной без правок UI.
- **Баланс в ScriptableObject.** Эффекты улучшений (сила клика, автодоход), настройки кликера и UI — в `GameSettings` и вложенных SO, доступ через `AssetProvider`; предметы связаны с серверными по `ProductId`.

## Запуск

1. Поднять бэкенд PriceForge: `docker compose up -d --build` в его репозитории. API — `http://localhost:8080` (адрес задан в `ApiClient`), разрешённый origin для CORS — `http://localhost:8000`.
2. В редакторе: открыть папку в Unity 6000.3, сцена `Assets/_Game/Scenes/Game.unity`, Play.
3. В браузере: собрать WebGL и отдать папку сборки на порту 8000, например `python -m http.server 8000`. В сборке включён Decompression Fallback, поэтому сжатые файлы открываются и на простом сервере без заголовка `Content-Encoding`.
